Shoppable Cart

Documentación de uso, configuración y personalización del script shoppable-cart.js

1. ¿Qué hace este script?

El script crea una interfaz de productos y un carrito directamente desde JavaScript. No necesita que el HTML tenga previamente el catálogo: al inicializarse genera el botón “Ver productos”, el panel lateral de productos/carrito y el modal de detalle.

El catálogo se define dentro del propio archivo mediante el arreglo P. La moneda está configurada inicialmente como COP.

El archivo funciona como un componente autocontenido: agrega sus propios estilos, crea sus elementos HTML y administra el estado del carrito en memoria.

2. Instalación básica

Guarda shoppable-cart.js en tu proyecto y cárgalo desde el HTML:

<script src="shoppable-cart.js"></script>

También puedes indicar un elemento específico donde se insertará la interfaz usando data-target:

<div id="mi-carrito"></div>

<script src="shoppable-cart.js" data-target="#mi-carrito"></script>

Si no se especifica data-target, el script utiliza document.body como contenedor.

3. Cómo agregar o modificar productos

Los productos se encuentran en el arreglo P. Cada producto utiliza esta estructura:

{
  id: "1",
  name: "Nombre_producto_1",
  description: "Descripcion_producto_1",
  image: "URL_imagen_producto_1",
  url: "URL_oficial_producto_1",
  variants: [
    {
      id: "v1",
      name: "Variante_1",
      image: "URL_imagen_variante_1",
      price: 10000
    }
  ],
  specifications: [
    "Caracteristica_1",
    "Caracteristica_2"
  ]
}
PropiedadUso
idIdentificador único del producto.
nameNombre que se muestra al usuario.
descriptionDescripción del producto.
imageURL de la imagen principal.
urlURL que se abre al comprar.
variantsLista de variantes disponibles.
specificationsArreglo de características. Está definido en el modelo de datos, pero actualmente no se muestra en el modal.

4. Variantes

Cada variante tiene su propio id, nombre, imagen y precio. El usuario puede seleccionar la variante desde el modal de producto.

El carrito identifica un artículo mediante la combinación de productId y variantId. Por eso, dos variantes del mismo producto pueden mantenerse como artículos separados.

Importante: aunque cada variante tiene una imagen, el código actual guarda la imagen de la variante al agregarla al carrito, pero el modal no cambia automáticamente la imagen principal cuando se selecciona otra variante.

5. Elegir dónde aparece el componente

Por defecto, ui() utiliza document.body. Para colocarlo dentro de otro elemento, usa data-target.

<section id="zona-productos"></section>

<script
  src="shoppable-cart.js"
  data-target="#zona-productos">
</script>

El selector debe coincidir con un elemento existente en la página.

6. Personalizar apariencia

Los estilos se generan automáticamente dentro de la función css(). Las clases principales son:

ClaseElemento
.spbBotón “Ver productos”.
.sppPanel lateral del catálogo y carrito.
.spiFila de un producto dentro del carrito.
.spqControl de cantidad − / +.
.spbuyBotón “PAGAR TODO”.
.spmVentana modal del producto.
.addBotón “Agregar al carrito”.
.buyBotón “Comprar ahora”.

Por ejemplo, para cambiar el ancho del carrito lateral, modifica .spp:

.spp{
  width:450px;
}

Para cambiar el color principal de los botones:

.spbuy{
  background:#0066cc;
}

7. Cómo funciona internamente

Estado

El carrito se mantiene en cart. El producto seleccionado se guarda en product, la variante en variant y la cantidad del modal en qty.

Agregar productos

add(p,v,n) comprueba si ya existe la combinación producto/variante. Si existe, incrementa la cantidad; si no, crea un nuevo artículo.

Cambiar cantidades

change(p,v,n) aumenta o reduce la cantidad. Cuando la cantidad baja de 1, el artículo se elimina.

Eliminar

remove(p,v) elimina una combinación concreta de producto y variante.

Total

total() suma precio × cantidad de todos los artículos.

Moneda

La función money() utiliza Intl.NumberFormat("es-CO") y la moneda definida en C.currency.

var C = { currency: "COP" };

Para otro código de moneda podrías cambiar ese valor, aunque el formato regional seguiría siendo es-CO hasta que también se modifique la función.

8. ¿Qué ocurre al comprar?

La función checkout() no procesa un pago directamente. Recorre los artículos del carrito y abre en una pestaña nueva la URL definida en cada producto.

cart.forEach(function(i){
  if(i.url) window.open(i.url,"_blank");
});

El botón “Comprar ahora” hace algo similar, pero abre directamente la URL del producto seleccionado.

Por tanto: este script actualmente es una interfaz de carrito y redirección. No contiene pasarela de pagos, cálculo de envío, inventario, backend ni persistencia del carrito.

9. Limitaciones actuales y puntos a tener en cuenta

  • El carrito vive solamente en memoria: al recargar la página se pierde.
  • No hay conexión con una base de datos.
  • No existe autenticación de usuarios.
  • No se procesa un pago dentro del script.
  • El botón “PAGAR TODO” abre la URL individual de cada artículo.
  • specifications está definida, pero renderProduct() no la presenta actualmente.
  • La imagen de la variante seleccionada no reemplaza la imagen principal del modal.
  • El catálogo se modifica directamente editando el JavaScript.
  • El script crea estilos automáticamente, por lo que la personalización se hace principalmente dentro de css().

10. Guía rápida de edición

  1. Abre shoppable-cart.js.
  2. Busca var C si necesitas cambiar la moneda.
  3. Busca var P para modificar el catálogo.
  4. Dentro de cada producto cambia nombre, descripción, imágenes, URL y variantes.
  5. Dentro de css() cambia colores, tamaños, posiciones y estilos.
  6. En data-target define el lugar donde aparecerá el componente.
  7. Prueba primero en una página de desarrollo antes de publicarlo.

12. Script completo

Este es el script completo utilizado como base de esta documentación:

(function(){
  "use strict";

  var C = { currency: "COP" };
  var P = [
    {
      id: "1",
      name: "Nombre_producto_1",
      description: "Descripcion_producto_1",
      image: "URL_imagen_producto_1",
      url: "URL_oficial_producto_1",
      variants: [
        { id: "v1", name: "Variante_1", image: "URL_imagen_variante_1", price: 10000 },
        { id: "v2", name: "Variante_2", image: "URL_imagen_variante_2", price: 15000 }
      ],
      specifications: ["Caracteristica_1","Caracteristica_2"]
    },


    {
      id: "2",
      name: "Nombre_producto_2",
      description: "Descripcion_producto_2",
      image: "URL_imagen_producto_2",
      url: "URL_oficial_producto_2",
      variants: [
        { id: "vb1", name: "Variante_A", image: "URL_imagen_variante_A", price: 20000 },
        { id: "vb2", name: "Variante_B", image: "URL_imagen_variante_B", price: 25000 }
      ],
      specifications: ["Caracteristica_3","Caracteristica_4"]
    }
  ];

  var cart = [], product=null, variant=null, qty=1;

  function money(n){return new Intl.NumberFormat("es-CO",{style:"currency",currency:C.currency,maximumFractionDigits:0}).format(n)}
  function total(){return cart.reduce((a,i)=>a+i.price*i.quantity,0)}
  function count(){return cart.reduce((a,i)=>a+i.quantity,0)}

  function add(p,v,n){
    var i=cart.find(x=>x.productId===p.id&&x.variantId===v.id);
    if(i){i.quantity+=n;}else{
      cart.push({productId:p.id,variantId:v.id,name:p.name,variant:v.name,image:v.image||p.image,price:v.price,quantity:n,url:p.url});
    }
    renderCart();
  }

  function change(p,v,n){
    var i=cart.find(x=>x.productId===p&&x.variantId===v);
    if(!i)return;
    i.quantity+=n;
    if(i.quantity<1)cart=cart.filter(x=>x!==i);
    renderCart();
  }

  function remove(p,v){cart=cart.filter(i=>!(i.productId===p&&i.variantId===v));renderCart()}

  function checkout(){
    if(!cart.length)return;
    cart.forEach(i=>{ if(i.url) window.open(i.url,"_blank"); });
  }
  function css(){
    if(document.getElementById("shoppable-css"))return;
    var s=document.createElement("style");
    s.id="shoppable-css";
    s.textContent=`
      .spb{position:absolute;bottom:20px;right:20px;z-index:99990;background:#111;color:#fff;border:0;border-radius:9px;padding:12px 17px;font:600 14px Arial;cursor:pointer}
      .spp{position:fixed;top:0;right:0;width:350px;height:100%;background:#fff;border-left:1px solid #ccc;box-shadow:-5px 0 20px rgba(0,0,0,.25);padding:15px;display:none;overflow-y:auto}
      .spp.on{display:block}
      .spi{display:flex;justify-content:space-between;align-items:center;margin:8px 0}
      .spq{display:flex;gap:5px;align-items:center}
      .spq button{width:25px;height:25px;border:1px solid #ccc;background:#eee;cursor:pointer}
      .spbuy{width:100%;margin-top:10px;padding:13px;border:0;border-radius:8px;background:#111;color:#fff;font-weight:700;cursor:pointer}
      .spm{position:fixed;top:50%;left:50%;transform:translate(-50%,-50%);width:400px;background:#fff;border-radius:10px;box-shadow:0 5px 20px rgba(0,0,0,.25);padding:20px;display:none;z-index:99999}
      .spm.on{display:block}
      .spm img{max-width:100%;border-radius:8px;margin-bottom:10px}
      .spm h2{margin:0 0 10px}
      .spm .spq{margin:10px 0}
      .spm button{margin:5px 0;padding:10px;width:100%;border:0;border-radius:8px;cursor:pointer}
      .spm .add{background:#28a745;color:#fff}
      .spm .buy{background:#111;color:#fff}
    `;
    document.head.appendChild(s);
  }

  function ui(target){
    var container = target ? document.querySelector(target) : document.body;
    var b=document.createElement("button");
    b.id="spb";b.className="spb";b.textContent="Ver productos";b.onclick=openCatalog;
    container.appendChild(b);

    var p=document.createElement("div");
    p.id="spp";p.className="spp";
    p.innerHTML="<h3>Productos</h3><div id='spl'></div><h4>Mi carrito</h4><div id='spitems'></div><button class='spbuy' id='spbuy'>PAGAR TODO</button>";
    container.appendChild(p);

    var m=document.createElement("div");
    m.id="spm";m.className="spm";
    container.appendChild(m);

    document.getElementById("spbuy").onclick=checkout;
  }

function catalog(){
  var e=document.getElementById("spl");
  e.innerHTML="";
  P.forEach(function(p){
    var d=document.createElement("div");

    // Bloque con nombre, descripción y precio
    d.innerHTML="<strong>"+p.name+"</strong><br>"+p.description+"<br>"+money(p.variants[0].price);

    // Control de cantidad (+ y −)
    var q=document.createElement("div");
    q.className="spq";
    q.innerHTML="<button>−</button><span>0</span><button>+</button>";
    d.appendChild(q);

    // Botón Ver más (abre modal con detalles)
    var more=document.createElement("button");
    more.textContent="Ver más";
    more.onclick=function(){openProduct(p)};
    d.appendChild(more);

    // Conexión de los botones + y −
    var minusBtn=q.children[0];
    var qtySpan=q.children[1];
    var plusBtn=q.children[2];
    var localQty=0;

    minusBtn.onclick=function(){
      if(localQty>0){
        localQty--;
        qtySpan.textContent=localQty;
        if(localQty===0) remove(p.id,p.variants[0].id);
        else change(p.id,p.variants[0].id,-1);
      }
    };

    plusBtn.onclick=function(){
      localQty++;
      qtySpan.textContent=localQty;
      if(localQty===1) add(p,p.variants[0],1);
      else change(p.id,p.variants[0].id,1);
    };

    e.appendChild(d);
  });
}

  function renderCart(){
    var e=document.getElementById("spitems");
    if(!e)return;
    e.innerHTML="";
    if(!cart.length){e.textContent="Tu carrito está vacío";return;}
    cart.forEach(function(i){
      var d=document.createElement("div");
      d.className="spi";
      d.innerHTML=i.name+" — "+money(i.price*i.quantity);
      var q=document.createElement("div");
      q.className="spq";
      q.innerHTML="<button>−</button><span>"+i.quantity+"</span><button>+</button>";
      q.children[0].onclick=function(){change(i.productId,i.variantId,-1)};
      q.children[2].onclick=function(){change(i.productId,i.variantId,1)};
      d.appendChild(q);
      var r=document.createElement("button");
      r.textContent="×";r.onclick=function(){remove(i.productId,i.variantId)};
      d.appendChild(r);
      e.appendChild(d);
    });
    var t=document.createElement("div");
    t.innerHTML="<strong>Total: "+money(total())+"</strong>";
    e.appendChild(t);
  }

  function openCatalog(){
    catalog();renderCart();
    document.getElementById("spp").classList.add("on");
  }

  function openProduct(p){
    product=p;variant=p.variants[0];qty=1;
    renderProduct();
    document.getElementById("spm").classList.add("on");
  }

  function closeProduct(){document.getElementById("spm").classList.remove("on")}

  function renderProduct(){
    var m=document.getElementById("spm");
    m.innerHTML="<h2>"+product.name+"</h2><img src='"+product.image+"'><p>"+product.description+"</p>";

    var v=document.createElement("select");
    product.variants.forEach(function(vr){
      var o=document.createElement("option");
      o.value=vr.id;o.textContent=vr.name+" — "+money(vr.price);
      v.appendChild(o);
    });
    v.onchange=function(){variant=product.variants.find(x=>x.id===this.value)};
    m.appendChild(v);

    var q=document.createElement("div");
    q.className="spq";
    q.innerHTML="<button id='menos'>−</button><span>"+qty+"</span><button id='mas'>+</button>";
    m.appendChild(q);

    m.querySelector("#menos").onclick=function(){ if(qty>1){ qty--; renderProduct(); } };
    m.querySelector("#mas").onclick=function(){ qty++; renderProduct(); };

    var addBtn=document.createElement("button");
    addBtn.className="add";addBtn.textContent="Agregar al carrito";
    addBtn.onclick=function(){add(product,variant,qty);closeProduct()};
    m.appendChild(addBtn);

    var buyBtn=document.createElement("button");
    buyBtn.className="buy";buyBtn.textContent="Comprar ahora";
    buyBtn.onclick=function(){window.open(product.url,"_blank")};
    m.appendChild(buyBtn);

    var closeBtn=document.createElement("button");
    closeBtn.textContent="Cerrar";
    closeBtn.onclick=closeProduct;
    m.appendChild(closeBtn);
  }

  function init(){
    css();
    var target = document.currentScript.getAttribute("data-target");
    ui(target);
  }

  if(document.readyState==="loading")document.addEventListener("DOMContentLoaded",init);else init();

})();
